# SongSetMaker
Manage Song Library and Create Song Sets for Worship Ministries

This application is under the Master branch

It requires a Deployed Google Sheet and the baseUrl needs to be updated with the URL in Services/RESTApiServices.cs

The Google Sheet also requires the AppsScript.txt file to be loaded in the Extensions - AppsScript
This provides the APIs for the Google Sheet. Once saved, the Apps Script must be deployed. The deployed URL is what is placed inte the RESTApiService.cs source file for the baseUrl
